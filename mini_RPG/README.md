Название: Mini RPG "LEGENDS"

Основная идея:
Игрок начинает игру с персонажем первого уровня. В начале он выбирает имя и класс героя. 
Каждый класс имеет свои характеристики. После создания персонажа игрок попадает в главное меню, 
где может просматривать характеристики героя, отправляться на сражение, получать награды и развивать персонажа.

Возможности программы:

* создание персонажа;
* выбор класса героя;
* просмотр характеристик персонажа;
* случайная встреча с противниками;
* сражения;
* получение опыта и золота;
* повышение уровня;
* восстановление здоровья;
* инвентарь с предметами;
* использование зелий;
* сохранение прогресса в файл;
* загрузка сохранённой игры;
* обработка некорректного ввода пользователя.

Классы персонажей:

* Воин — много здоровья, средняя атака;
* Маг — мало здоровья, высокая атака;
* Лучник — среднее здоровье и атака.

Противники:

* Гоблин;
* Скелет;
* Орк;
